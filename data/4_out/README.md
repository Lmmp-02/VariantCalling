# Generated outputs

`data/4_out/` is the runtime workspace for generated pipeline intermediates. DeepVariant examples/calls, offline unimodal and multimodal datasets, hap.py runtime outputs and other heavy artifacts are intentionally excluded from Git.

The only generated data retained here are compact `mosdepth_multimodal_benchmark/` summaries used to document the realised coverage of the benchmark conditions.

Curated main evaluation tables live in `results/`. Curated outputs from the supporting DeepVariant low-coverage study live in `studies/deepvariant_low_coverage/results/`.
