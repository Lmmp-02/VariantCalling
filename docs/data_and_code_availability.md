# Data and code availability — manuscript draft

Use the paragraph below after the Zenodo artefact record is published. Replace the software DOI placeholder when the `v1.0.0` software release has been archived and assigned a DOI.

All sequencing data used in this study are publicly available: Illumina data for HG002–HG005 and the GIAB v4.2.1 truth sets and confident regions were obtained from the Genome in a Bottle repository, and ONT data from the Oxford Nanopore Technologies Open Data Genome in a Bottle release 2025.01. The code and reproducibility companion are available at https://github.com/Lmmp-02/VariantCalling, release `v1.0.0` (software DOI: [to be added after release archiving]). Paper artefacts are archived on Zenodo under DOI https://doi.org/10.5281/zenodo.23804374 and include the prediction dumps, classification-head checkpoints and singleton-locus multimodal datasets used by the paper. The repository provides four reproduction levels: Level 0 regenerates the paper tables and generated figures from versioned results; Level 1 regenerates the analysis CSVs exactly from the archived prediction dumps; Level 2 retrains the lightweight heads and regenerates predictions and analyses from the archived multimodal datasets, with GPU reruns checked against the published seed ranges rather than for bit-exact equality; and Level 3 reconstructs the seven singleton-locus multimodal datasets from the public GIAB and ONT inputs using DeepVariant 1.9.0 and checks their availability-group candidate counts against the paper. All custom-model evaluations remain offline, candidate-level analyses of the singleton-locus candidate set and do not constitute an end-to-end variant-calling comparison with DeepVariant.
